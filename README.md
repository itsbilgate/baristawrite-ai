# baristawrite-ai
AI-powered ESP writing assessment for English for Baristas.

## Project documentation
- [Assessment plan](docs/assessment-plan.md): source context, proposed writing objectives, first task prototype, draft analytic rubric, alignment map, and development procedure.

## Status
Initial assessment plan drafted. The proposed specific writing objectives are derived from the general course goals and barista workplace context; they are not quoted verbatim from the source case study. The assessment has not yet been piloted or validated.

## Next step
Develop a small prototype that provides rubric-aligned formative feedback on a learner's response to the customer-complaint task.
